# Créditos de las fotografías de equipos

Las imágenes provienen de **Wikimedia Commons** y se usan bajo sus licencias libres (atribución requerida). 
Son fotografías de **equipos del mismo tipo/marca/línea** disponibles con licencia libre; no necesariamente son la unidad física del inventario USCO. 
Para usar la foto real de cada unidad, reemplaza el archivo `usco-eq-XXX.jpg` de esta carpeta (o cambia la URL desde Coordinador → Inventario → Editar).
